# Command: Produce Meeting Infographic

Send this to The Artist:

```text
Produce Meeting Infographic

Limitless lifelog: [meeting name, topic, or date YYYY-MM-DD]
Audience or handling: [Board / Internal / optional]
```

The Artist will search Limitless, extract minutes without inventing facts, and build one portrait HTML page from the `meeting-infographic` template (timeline, takeaways, actions, decisions only if they were actually made).

Open the HTML and print to PDF for a one-page packet.
