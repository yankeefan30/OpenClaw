# Command: Apply Lifelog Feedback

Send this to The Artist with a deck attached.

```text
Apply Lifelog Feedback

Attached deck: [this file / Slides URL / Drive link]
Limitless lifelog: [meeting name, topic, or date YYYY-MM-DD]
Audience: [Board / CVS ELT / Aetna ELT / other]
Do not overwrite the original. Version the update.
Stay on the CVS Health 2025 Enterprise Template.
```

The Artist will:

1. Search Limitless for that lifelog.
2. Pull directed feedback out of the transcript.
3. Copy the attached deck to the next version.
4. Apply the edits.
5. Run the Final Pre-Board Quality Gate.
6. Return updated Slides, PPTX, PDF, the lifelog used, and a revision summary.

It will not invent numbers to satisfy a comment. If several lifelogs could match, it will list them once.
