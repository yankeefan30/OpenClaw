# Recommended Notion page layout

## Executive Political Health (top page)

1. **Privacy callout** — Private · evidence-grounded · decision support only  
2. **Today** — score table + one-sentence executive readout  
3. **What changed since yesterday?**  
4. **Top 3 actions for today**  
5. **Relationships needing attention**  
6. **Relationships gaining momentum**  
7. **Open political risks**  
8. **Decision and commitment follow-up**  
9. **Signals to verify**  
10. **Legend** — bands, confidence, coverage, evidence standards  
11. **Linked views** (already appended on the live page):
    - Today's Daily Assessment
    - 7-Day Score History
    - 30-Day Score History
    - Relationship Heat Map
    - Tier 1 Watch List
    - Momentum Relationships
    - Open P0/P1 Actions
    - Open High/Critical Risks
    - Signals to Verify
    - Evidence Audit Trail
12. **Child page: Weekly Review**
13. **Child databases** (full-page, not cluttering the hero)

### Reading order for a busy executive (≤3 minutes)

1. Today score + readout  
2. Top actions  
3. Tier 1 Watch List  
4. Open High/Critical Risks  
5. Stop — deeper audit only if Human Review Required  

## Database default views (on each DB)

| Database | Recommended default view |
|----------|---------------------------|
| Daily Assessments | Sort Assessment Date DESC |
| Strategic Relationships | Heat map sort (Tier ASC, Health ASC) |
| Relationship Daily Assessments | Assessment Date DESC |
| Dimension Scores | Assessment Date DESC, Dimension |
| Interactions | Interaction DateTime DESC |
| Evidence Ledger | Event DateTime DESC |
| Risks & Opportunities | Open + severity board |
| Actions | Open P0/P1 |
| Analysis Runs | Schedule Time DESC |

## Templates (manual)

Create Notion button/templates on Strategic Relationships for “New Tier 1 person” pre-filling Strategic Tier, Do Not Infer boilerplate, and Relationship Objective prompt.
